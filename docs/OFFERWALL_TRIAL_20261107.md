## 1. 本人決定の試験条件

- AdSense Offerwall（リワード広告）を **通常の記事ページに限定**する。
- メータリングしきい値は **4回の対象ページ閲覧**。サイト全体4回と混同しない。除外ページはカウント対象外（Google公式仕様）。
- リワード広告の視聴完了後は **24時間アクセス許可**。管理画面の対応範囲と実機動作を確認する。
- `/`（トップ）、`/compare/*/`（12計算機）、`/category/*/`（カテゴリナビゲーション）、`/about/`、`/operator/`、`/privacy/`、`/disclaimer/`、`/contact/`、`/404.html` は**対象外**。
- 公式リンク、最新の重要なお知らせ、計算結果、入力フォーム、共有操作、プライバシー／問い合わせ導線を妨げない。
- Adsterraの既存Social Barはサイト専用の設定・コードを保全し、Googleとの重複全画面表示や操作干渉がある場合は該当枠を停止・再調整する。別サイトの広告コードは流用しない。

- `src/build.mjs` が生成するのはトップ、12種のWebApplication比較ページ、カテゴリ4ページ、共通5ページ、404。比較ページの `search-guide` は計算機と同一URLであり、独立記事ではない。
- **独立した通常記事ページはまだ存在しない**。現在のURLのどれかに無理にOfferwallを付けると本人の対象条件に反するため、配信はまだ開始しない。
- `src/build.mjs` にAdSense accountメタタグはあるが、Google広告配信タグは確認できず、CSPの `script-src` は自サイトとAdsterraの配信元のみ。**メタタグだけでOfferwallが動くとは扱わない**。
- `content/ads.json` にはAdsterra承認済みSocial Barが設定済み。ただし広告表示・インプレッション・収益は別途実測確認が必要。
- `docs/STATUS.md` では独立したアクセス解析は未導入。導入前後の数値比較に必要な測定を先に整える。
- F計画広告本部の2026-11-07の引継ぎ記録ではAdSenseのサイト承認0件／全22媒体が準備中とされている。**今回AdSense管理画面への直接ログインでは再検証できていない**ので、対象サイトの審査通過は未確認。Gmail検索でも対象承認メールは見つからなかったが、それだけで審査中とは断定しない。
- この文書の追加は**導入準備**であり、Offerwall公開・新規収益・サイト承認の完了報告ではない。

## 3. 実行順序・担当

### A. Webサイト日次運営・検索対策担当

1. 計算機の無料・登録不要方針を変更せず、独立した本文記事（候補 `/articles/`）を少数制作する。実在の価格やキャンペーンは公式出典・確認日を記載。説明が薄い記事の量産はしない。
2. 各記事にタイトル、見出し、参照先、canonical、公開日／更新日、サイトマップ、カテゴリへの自然な内部リンクを設定。
3. 導入前の自然流入・対象記事PV・訪問数・離脱率・回遊率・広告表示/収益を正規の解析ツールで把握。計算入力の個人値や個別条件を計測送信しない。
4. 記事とトップ・計算機の切り離しを自動テストとモバイル操作で確認。
5. 完了まで `/articles/` は管理画面で設定しない。実際の公開URLパターンが異なるなら読戻して置き換える。

### B. F計画 広告収益化・配置運用担当

1. AdSenseの対象URL `https://ima-docchi-2x9.pages.dev/` の**サイト個別承認**とOfferwall利用可能を実管理画面で確認する（ads.txt承認は別）。未承認なら待機し、重複申請なし。
2. 正規AdSenseタグ、必要なCSP通信先・プライバシー／Cookie説明・同意管理を実装し、対象外ページでフォームや主要操作を妨げないことを確認する。禁止表現やクリック誘導をしない。
3. `AdSense → プライバシーとメッセージ → Offerwall` で対象サイトを指定。**包含のみ `path-include /articles/`**（独立記事を実際に公開した後）、しきい値4、リワード広告完了後24時間を設定。「最適化」によって4の条件が自動変更されないよう、試験中は最適化OFFを優先。
4. まず下書き／テストで実機・PC・スマホを確認。対象外に出ない、閉じる動作、広告未配信時、連続訪問、24時間解放、Adsterraとの表示干渉を検証してから公開。
5. 公開後14日間の試験。十分な対象PVがない場合は結論を保留し、日数のみで効果を断定しない。人為的なPV・広告視聴・自己クリックはしない。

## 4. 評価指標と停止基準

- 主要：Google Offerwall表示数、視聴選択率、視聴完了率、リワード売上、1,000対象記事PVあたりの合算広告売上。
- 副次：記事離脱率、セッションあたり閲覧ページ数、再訪、検索流入、Adsterra広告収益、関連アフィリエイトのクリック数・成果確定率。
- ベースラインは**開始前の比較可能な期間（原則14日間）**を採り、導入後と同じ定義・計測方法で比較。季節要因、流入元、少標本の注意を付ける。
- 停止：主要機能の操作妨害、対象外表示、同意・プライバシー不備、審査制限、モバイルで閉じられない／全面広告の競合、明らかな離脱悪化など。影響があればOfferwallを一時停止して原状回復を優先。
- AdSense、Adsterraそれぞれの承認・コード配置・本番表示・計測・収益を**別々の状態**として記録する。
